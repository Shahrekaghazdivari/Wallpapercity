# سایت چندصفحه‌ای شهر کاغذ دیواری

فایل‌های اصلی:
- `index.html` صفحه اصلی
- `styles.html` سبک‌ها
- `gallery.html` گالری
- `about.html` درباره ما
- `contact.html` ارتباط با ما
- `style.css` ظاهر سایت
- `script.js` منوی موبایل، فرم واتساپ و گالری

## انتشار در GitHub Pages
همه فایل‌ها را در همان مخزن قبلی جایگزین یا آپلود کنید. فایل `index.html` باید در ریشه مخزن باقی بماند.

- `3d-wallpaper.html` صفحه اختصاصی کاغذ دیواری سه‌بعدی
